# T1059.001 — Command and Scripting Interpreter: PowerShell

## Attacker behavior
PowerShell is the primary execution tool in modern attacks: encoded commands,
execution-policy bypass, hidden windows, in-memory payload download (IEX/WebClient).

## Telemetry prerequisites
- Script Block Logging enabled (registry EnableScriptBlockLogging=1) → Event ID 4104
- Agent ossec.conf must include Microsoft-Windows-PowerShell/Operational channel
  (default agent collects only Application/Security/System)
- Sysmon EID 1 for command-line level detection (encoded flags live in command line,
  NOT in 4104 decoded script text)

## Detection logic
- rule 100202 (validated): child of built-in 91837; matches IEX/Invoke-Expression/
  Net.WebClient/DownloadString in 4104 scriptBlockText → level 10
- rule 100201 (follow-up): child of Sysmon base 61000 + eventID 1; matches
  -enc/-nop/-w hidden in commandLine → level 10

## Validation plan

| # | Test command | Expected alert | Result |
|---|--------------|----------------|--------|
| 1 | `powershell.exe -enc <b64>` | rule 100201, level 10 | ⏳ follow-up |
| 2 | `powershell.exe -c "IEX (New-Object Net.WebClient).DownloadString(...)"` | rule 100202, level 10 | ✅ detected |

## Lessons learned
- Wazuh first-match semantics: child rules (if_sid) are the reliable pattern
- Encoded-command flags (-enc) live in process command line, not in 4104
- DNS failure of download does not prevent detection: attempt is logged in 4104
- Default agent telemetry is the silent killer of detections: verify channels before writing rules
