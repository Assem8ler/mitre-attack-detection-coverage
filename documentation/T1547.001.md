# T1547.001 — Boot or Logon Autostart Execution: Registry Run Keys

## Attacker behavior
Adversaries add values to Run/RunOnce keys (HKCU/HKLM) so malware executes
at user logon: reg add, New-ItemProperty, Set-ItemProperty.

## Existing built-in coverage
- Wazuh built-in rule 91844 (level 12): Run key addition via PowerShell 4104 script blocks
- Sysmon EID 13 built-in (0860-sysmon_id_13.xml): registry value set on Run keys
- Detection engineering note: know existing coverage before writing new rules

## Project rule
- rule 100401 (level 12): child of 91844 — project-validated alert with MITRE T1547.001 tag

## Telemetry
- PowerShell Script Block Logging (4104) — enabled in T1059.001 step
- Follow-up gap: non-PowerShell modifications (reg.exe) require Sysmon EID 13 telemetry

- Built-in coverage analysis is part of detection engineering: 91844 already existed;
  project rule adds validated alerting and MITRE tagging on top
