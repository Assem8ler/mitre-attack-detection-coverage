# T1021.002 — Remote Services: SMB/Windows Admin Shares

## Attacker behavior
Adversaries use admin shares (C$, ADMIN$, IPC$) for lateral movement:
net use, PsExec, copy payload to remote host.

## Telemetry
- Security Event ID 5140 (network share accessed)
- Built-in rule 67017 intercepts 5140 first; project rule is child of 67017
- Prerequisite: audit "Other Object Access Events" success enabled (from T1053.005)

## Detection logic
- rule 100601 (level 10): child of 67017 + pcre2 pattern (C$|ADMIN$|IPC$)
- shareName format: `\\*\C$` (UNC path)

## Validation plan

| # | Test command | Expected alert | Result |
|---|--------------|----------------|--------|
| 1 | `net use \\127.0.0.1\C$ /user:CYBERLAB\it.admin` | 100601, level 10 | ✅ detected |

## Lessons learned
- Built-in rule 67017 intercepts 5140; standalone custom rule on 5140 cannot win
- shareName comes as `\\*\C$` (UNC), shareLocalPath as `\\?\C:\` (device path)
- Audit prerequisite reused from T1053.005 (Object Access success enabled)
