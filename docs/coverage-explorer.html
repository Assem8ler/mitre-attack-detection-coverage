◆ About this layer

Custom Wazuh detection coverage built across two home labs: 6 techniques validated in the mitre-attack-detection-coverage project (custom XML rules, attack + benign validation), 5 techniques detected in the active-directory-purple-team-lab (Kerberoasting, Pass-the-Hash, network scan, brute force, domain discovery), and 3 planned. Every green cell links to a firing Wazuh rule and a dashboard alert screenshot in the repositories.

Source of truth: attack-navigator-layers/coverage.json · detection repo · AD purple team lab. All testing performed in an isolated VirtualBox host-only network for educational purposes.
